# Maison Payen 1730 : site vitrine

Site statique (HTML/CSS), FR à la racine, EN dans /en/.

Mise en ligne sur GitHub Pages :
1. Pousser le contenu de ce dossier à la racine d'un dépôt.
2. Settings > Pages : Source « Deploy from a branch », branche main, dossier / (root).
3. Settings > Pages > Custom domain : saisir le domaine, puis cocher « Enforce HTTPS ».
